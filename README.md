# astrbot_plugin_user_blacklist

> 在 AstrBot 配置界面填入 QQ 号，就能让机器人**屏蔽**那个人 —— 群聊也好、私聊也好，他发的消息都会被直接丢掉：不回复、不进大模型、不烧 token，对方甚至不知道发生了什么。

## ✨ 特性

| 特性 | 说明 |
| --- | --- |
| 🎛️ 图形化配置 | 面板 → 插件管理 → 用户黑名单 → 在「屏蔽名单」里填 QQ 号即可，一行一个 |
| 🌐 全场景生效 | 群聊、私聊、@机器人、唤醒词触发，一律拦截 |
| 🔇 真·静默 | 默认连"你已被屏蔽"都不回，对方察觉不到（也可选配提示语） |
| 🛡️ 管理员豁免 | 可选开关，防止手滑把自己锁在门外 |
| 🎯 范围可选 | `both` 全屏蔽 / `group` 只封群聊 / `private` 只封私聊 |
| 📝 拦截日志 | 可选，每次拦截在日志里留痕，方便确认生效 |
| 🔥 免重载热更新 | 直接编辑插件目录的 `blacklist.json`，保存即生效，不用重载插件 |

> 📌 `blacklist.json` 是你的**本地名单文件**，已被 `.gitignore` 排除、不会上传到仓库（仓库里只有一份 `blacklist.json.example` 示例）。因为这个文件里往往会写真实 QQ 号，不适合公开。

## 📦 安装

1. 把 `astrbot_plugin_user_blacklist` 整个文件夹放进 `AstrBot/data/plugins/` 目录；
2. 重启 AstrBot，或在**面板 → 插件管理**里重载插件；
3. 打开该插件的配置，在「屏蔽名单」中填入要屏蔽的 QQ 号并保存。

## ⚙️ 配置项

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enable` | bool | `true` | 总开关，关闭后名单全部失效 |
| `blacklist` | list | `[]` | 屏蔽名单，填 QQ 号 / 用户 ID，一行一个 |
| `scope` | string | `both` | `both` 群聊+私聊 / `group` 仅群聊 / `private` 仅私聊 |
| `ignore_admin` | bool | `true` | 名单中的 AstrBot 管理员不被屏蔽 |
| `notice` | string | 空 | 留空=完全静默；填写后会回一句该文本，依然不进入大模型 |
| `log_block` | bool | `true` | 是否在日志中记录每次拦截 |

## 🔍 工作原理

插件以**最高优先级**（`priority=100`）挂载在所有消息事件上：

```python
@filter.event_message_type(filter.EventMessageType.ALL, priority=100)
```

一旦发送者命中名单，立即调用 `event.stop_event()` **截断整条事件传播链**。因为拦截发生在任何命令解析与大模型请求之前，所以：

- 机器人不会回复，也不会调用 LLM（省钱、省额度）；
- 命令、工具调用、人格回复等后续环节全部不会执行；
- 对方在群里 @ 机器人同样无效。

## ❓ 为什么不用 QQ 自带的拉黑？

QQ 的好友黑名单**只拦私聊**，群消息照样收得到，也挡不住机器人在群里被 @ 时的回复；而机器人本身是"无感情地接收一切消息"的程序，所以屏蔽只能在**框架事件层**做——这就是本插件存在的意义。
